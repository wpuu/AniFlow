# AWS会否另收税，以及当前是否需要免税操作

2026-10-25，Asia/Shanghai。范围是本次AWS全球账户东京WorkSpaces实验的AWS账单代收税，不是对全部中国税务申报义务作结论。

## 已查到的账户事实

- 税务设置表的地址国家代码为 **CN（中国）**。
- 卖家显示 **Amazon Web Services, Inc.**。
- TRN状态显示“-”，不能把它说成已有有效免税证。
- 当期账单周期2026年10月，总计税费 **USD0.00**。
- 本轮没有修改国家、地址、税号、付款方式或免税设置，没有提交免税证明或联系客服。

[仅保留国家/卖家/税额的脱敏证据](2026-10-25-aws-tax-jurisdiction-evidence.json)。不保存到公开记录的资料包括完整账户编号、街道地址、联系方式、税号及付款资料。

## 当前预测

基于这些事实和AWS官方规则，**目前没有发现会因选择东京WorkSpaces而额外加收日本10%消费税的依据，费用预估可暂按AWS代收税$0处理**。这是对当前资料的判断，不是税务豁免审批，也不是未来发票永久零税保证。

AWS在开票时依据有效税号、账单地址、联系地址及相应付款资料等确定账户所在地和税费。日本规则针对日本账户地址客户；服务器在东京不等于客户税务所在地变成日本。不能把AWS中国区账单的6%直接套到本AWS Inc.全球账户。APAC税表未列大陆只能作为辅助，不能单凭缺少条目宣称永久免税。

## 当前怎样处理

1. **无需为了这次东京实验修改现有CN税务资料。** 当前国家代码与用户已确认的大陆使用地一致；没有证据表明需要更正。若以后资料确有错误，只能按真实情况更正，且修改前需用户同意。
2. **无需申请美国州免税。** 当前观察的税址不是美国州，未发现对应免税证资格或必要性；也没有通用个人免税开关。税号不自动等于免税。AWS免税证审核会产生Support流程，用户已禁止联系客服，本轮不提交。[官方税务与免税流程](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/manage-account-payment.html)。
3. 赠金用于抵扣合格服务费用，**不能支付适用交易税**；它本身不构成免税资格。也不应套用其他国家的税基规则，声称所有税都按赠金抵扣前或抵扣后统一计算。[赠金条款第7项](https://aws.amazon.com/awscredits/)。
4. 若税务资料、卖家或购买类型发生变化，需重新判断；最终以实际发票为准。当前预算中税按0预估，并不授权任何额外现金支出。
