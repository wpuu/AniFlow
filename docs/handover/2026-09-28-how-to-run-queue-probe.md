# 你要做的测试：一页说明

`2026-09-28 | Claude Opus 5.5` | 分支 `main` | HEAD `c9ee59f`

---

## 这个测试在问什么

Agnes 免费视频现在**长期排不上队**（我这边连续 75 分钟、上百次请求，一次都没挤进去）。

现在要确认一件事，它直接决定你那 9 个账号值不值钱：

> **排队是按账户算，还是全平台所有人共用一个队？**

| 结果 | 含义 |
|---|---|
| **按账户** | 9 个账号 = 9 倍视频产能，多 Key 抽卡策略成立，整个生产方案不用改 |
| **全平台共用** | 多账号对视频**完全无效**（对文字、图片仍然有效），产能模型要重做 |

我一个人测不出来——**只有一条 Key 的时候，这两种情况长得一模一样**。必须用你的多条 Key 在**同一瞬间**一起发请求。

---

## 你只需要做两步

### 第一步：把 Key 填进 `.env`

打开项目根目录的 `.env` 文件（没有的话，复制 `.env.example` 改名成 `.env`），找到这一行：

```
AGNES_API_KEYS=
```

把你手上的 Key **用英文逗号连起来**写在等号后面，不要有空格、不要换行：

```
AGNES_API_KEYS=sk-第一条,sk-第二条,sk-第三条,sk-第四条
```

有几条填几条。**至少要 2 条**，否则测不出结论。填 9 条最好。

> Key 只存在你本机这个文件里。`.env` 不会上传 GitHub，我也不会打印它。

### 第二步：双击运行

在 `scripts` 文件夹里找到 **`probe_queue_windows.ps1`**，右键 →「使用 PowerShell 运行」。

就这样，没有别的步骤。

---

## 你会看到什么

```
第 1 轮   10:49:33
   account-1   被拒     video_queue_full
   account-2   已入队   video_a1b2c3
   account-3   被拒     video_queue_full
   小结: 1 成功 / 2 被拒   <<< 混合结果，已可定论
```

**只要出现「混合结果」这一行，测试就成功了**——同一瞬间有的进得去有的进不去，只可能是按账户限流。程序会自己停下来给结论。

最后会打印三种结论之一：

- ✅ **队列按账户隔离** → 好消息，9 账号有效
- ⚠️ **全部被拒，无法区分** → 队列太挤，没测出来，见下面
- ✅ **当前有空位** → 全都进去了，说明此刻不拥挤

---

## 如果全部被拒

很可能会这样，因为队列现在基本是满的。这种情况**不代表失败，也不代表是全平台共用队列**——我在程序里专门没有把它判成结论，因为「平台满了」和「你每个账号各自都满了」此刻看起来一样，硬下结论就是骗你。

这时候改成挂机模式，让它自己蹲：

右键 `probe_queue_windows.ps1` →「编辑」太麻烦，直接在项目文件夹里按住 `Shift` 右键 →「在此处打开 PowerShell 窗口」，粘贴这一行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\probe_queue_windows.ps1 -Watch
```

它会每 20 秒发一轮，**一直发到抢出结论为止**，然后自己停。可以挂着不管，去睡觉都行。

---

## 顺带解决的第二个问题

只要有任何一条 Key 抢到队列位，程序不会停在「入队成功」，它会：

1. 一直等到视频真的生成完
2. 下载到 `output/queue-probe/`
3. **检查这条视频自不自带声音**

这是另一个一直悬着没答案的问题（Agnes 出的视频有没有原生音轨，直接影响配音方案怎么做）。一次跑完两个答案都有了。

视频下载下来之后，**请你自己看一遍**——我需要知道毛毡风格在动起来之后稳不稳，这个只能人眼判断。
