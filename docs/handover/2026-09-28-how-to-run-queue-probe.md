# 你要做的测试：一页说明

`2026-09-28 | Claude Opus 5.5` | 分支 `main`

> 上一版说明让你去改 `.env`——那是我的错。`.env` 这个文件项目里**根本不存在**，
> 而且 Windows 资源管理器不允许你新建以点开头的文件名。这版不需要任何文件操作。

---

## 这个测试在问什么

Agnes 免费视频现在**长期排不上队**（我这边连续 75 分钟、上百次请求，一次都没挤进去）。

要确认一件事，它直接决定你那些账号值不值钱：

> **排队是按账户算，还是全平台所有人共用一个队？**

| 结果 | 含义 |
|---|---|
| **按账户** | 多个账号 = 成倍视频产能，多 Key 抽卡策略成立，生产方案不用改 |
| **全平台共用** | 多账号对视频**完全无效**（对文字、图片仍然有效），产能模型要重做 |

我一个人测不出来——**只有一条 Key 的时候，这两种情况长得一模一样**。
必须用你的多条 Key 在**同一瞬间**一起发请求。

---

## 怎么跑（不用装任何东西）

1. 打开 https://github.com/wpuu/AniFlow
2. 点绿色的 **`Code`** 按钮 → **`Download ZIP`**
3. 解压，进 **`scripts`** 文件夹
4. 双击 **`队列测试-双击运行.bat`**
5. 它会让你粘 Key —— **一行一条，或者一行里用逗号隔开都行，粘完按两下回车**

没有别的步骤。不用装 Python，不用建文件，不用改配置。

> Key 只在这个窗口里用一次，不写进任何文件，不上传任何地方。
> 屏幕上只会显示每条 Key 的**最后 6 位**，方便你对号。

---

## 你会看到什么

```
第 1 轮   11:07:11
   账户 1     已入队   vid_a1b2c3
   账户 2     被拒     video_queue_full
   账户 3     被拒     video_queue_full
   小结: 1 成功 / 2 被拒   <<< 混合结果，已可定论
```

**只要出现「混合结果」那一行，测试就成功了**——同一瞬间有的进得去有的进不去，
只可能是按账户限流。程序会自己停下来给结论。

三种结论：

- **队列按账户隔离** → 好消息，多账号有效
- **全部被拒，无法区分** → 队列太挤，见下一节
- **当前有空位** → 此刻不拥挤，但还不能定队列模型

---

## 如果全部被拒（很可能）

队列现在基本是满的，大概率你第一次跑就是这个结果。

**这不代表失败，也不代表是全平台共用队列。** 我特意没把它判成结论——因为
「平台满了」和「你每个账号各自都满了」此刻看起来一模一样，硬下结论就是骗你。

这时候改双击 **`队列测试-挂机模式.bat`**，它每 20 秒发一轮，
**一直发到抢出结论为止**，然后自己停。挂着不用管，去睡觉都行。

---

## 顺带解决的第二个问题

只要有任何一条 Key 抢到位，程序不会停在「入队成功」，它会：

1. 一直等到视频真的生成完
2. 下载到你**桌面**的「AniFlow测试视频」文件夹
3. **自动检查这条视频自不自带声音**

这是另一个一直悬着的问题（直接影响配音方案怎么做）。一次跑完两个答案都有了。

视频下载下来之后**请你自己看一遍**——我需要知道毛毡风格动起来稳不稳，这个只能人眼判断。

---

## 测不出来也没关系

如果挂了很久还是抢不到，那本身就是结论：**免费视频档在当前时段不具备生产可用性**。
那样下一步就不是继续等，而是去评估付费档或换视频供应商。

把窗口截图发我就行，不用全屏。

| 项目 | 状态 |

它会在「1 成功 / 0 被拒」时误判成「混合结果」，给你一个**错误的好消息**。
